# Employee Attendance Management System

A full-stack Employee Attendance Management System built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.

The application allows employees to register, log in, manage daily attendance, calculate working hours, submit leave requests, and view their attendance and leave information.

HR users have a separate role-based dashboard where they can monitor employees, attendance records, and manage leave requests.

---

## 📌 Project Overview

The Employee Attendance Management System is designed to simplify employee attendance and leave management within an organization.

The system provides two main user roles:

### Employee

Employees can:

- Register an account
- Log in securely
- Check in for the day
- Check out after completing work
- Automatically calculate working hours
- View attendance history
- View attendance status
- Apply for leave
- View leave history
- View remaining leave balance
- View profile information

### HR

HR users can:

- Log in through the same login page using an HR account
- Access the HR Dashboard
- View employee statistics
- View all employees
- Activate/deactivate employee accounts
- Monitor employee attendance
- View check-in/check-out records
- View working hours
- View attendance status
- View all leave requests
- Approve or reject leave requests
- Manage employee attendance and leave information
